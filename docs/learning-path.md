# 학습 경로

한 장면에서 한 개념만 확인하고, 다음 단계로 넘어가기 전에 직접 값을 바꿔 결과를 관찰합니다.

## 1. 씬과 트랜스폼

- 장면: `004-01_*` ~ `004-04_*`
- 목표: GameObject, Transform, 위치/회전/크기, 기본 이동과 회전
- 확인: Inspector에서 Transform 값을 바꾸고 Play 전후 차이를 비교합니다.

## 2. 물리와 캐릭터

- 장면: `004-05_*`, `004-06_*`
- 목표: Collider, Rigidbody, Trigger, CharacterController
- 확인: 충돌과 Trigger 콜백의 차이, Kinematic 설정의 효과를 확인합니다.

## 3. 사운드와 카메라

- 장면: `004-07_*`, `004-08_*`, `004-09_*`
- 목표: AudioSource/AudioClip, 카메라 추적, Skybox
- 확인: 3D 사운드 거리와 카메라 움직임을 한 번에 하나씩 변경합니다.

## 4. 재사용과 시각 효과

- 장면: `004-10_*`, `004-11_*`
- 목표: Prefab, Particle System
- 확인: 원본 Prefab 변경이 인스턴스에 어떻게 반영되는지 확인합니다.

## 5. 조회와 흐름 제어

- 장면: `004-12_*` ~ `004-17_*`
- 목표: Raycast, 자주 쓰는 API, Coroutine, 씬 전환, 메서드 호출, PlayerPrefs
- 확인: 입력 → 조회 → 상태 변경 흐름을 작은 예제로 설명할 수 있는지 점검합니다.

## 6. UI와 콘텐츠

- 장면: `004-18_*` ~ `004-21_*`
- 목표: Unity UI, 모델링, 애니메이션
- 확인: UI 입력값이 게임 상태에 연결되는 경로와 애니메이션 재생 방식을 기록합니다.

각 단계가 끝나면 장면 파일명, 배운 개념, 직접 바꿔 본 값, 생긴 문제와 해결 방법을 짧게 기록합니다.
