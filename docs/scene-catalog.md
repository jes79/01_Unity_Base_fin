# 장면 카탈로그

장면 파일은 `Assets/01.Scenes/004`에 있습니다. 번호는 교안의 순서를 유지하고, 세부 장면은 접미사로 구분합니다.

| 범위 | 주제 | 예시 장면 |
|---|---|---|
| 004-01~04 | 이동, 회전, 점프, Transform | `004-01_01_Move.unity`, `004-04_06_RotateAround.unity` |
| 004-05 | Collision, Trigger, Rigidbody | `004-05_01_Collision.unity`, `004-05_03_Kinematic.unity` |
| 004-06 | CharacterController | `004-06-01_CharacterController.unity` |
| 004-07 | 사운드 재생과 AudioManager | `004-07-01_Play.unity`, `004-07-05_CsAudioManager.unity` |
| 004-08~09 | 카메라, Skybox | `004-08-01_MainCamera.unity`, `004-09_SkyBox.unity` |
| 004-10~11 | Prefab, Particle | `004-10_Prefab.unity`, `004-11_Particles.unity` |
| 004-12 | Raycast와 ScreenPointToRay | `004-12-01_RayCast.unity`, `004-12-03_ScreenPointToRay.unity` |
| 004-13 | Random, Distance, Find | `004-13-01_Distance.unity`, `004-13-03_Find.unity` |
| 004-14~17 | Coroutine, 씬 전환, 메서드 호출, PlayerPrefs | `004-14_Coroutine.unity`, `004-17_PlayerPrefs.unity` |
| 004-18 | Unity UI | `004-18-01_Text.unity` ~ `004-18-08_Dropdown02.unity` |
| 004-19~21 | 모델링, Mecanim, KeyFrame Animation | `004-19-01_Model01.unity`, `004-21-03_KeyFrameAnimation.unity` |

파일명이 추가되면 표의 해당 행을 갱신하고, 기존 장면을 삭제하거나 이름을 바꿀 때는 README와 노션 링크를 함께 확인합니다.
