# 문서 운영 규칙

## 실습 문서 형식

새 주제는 다음 순서로 기록합니다.

1. **목표:** 무엇을 이해하거나 실행하는가
2. **준비:** 필요한 장면, 컴포넌트, 입력
3. **실행:** 사용자가 따라 할 최소 단계
4. **관찰:** 값을 바꿨을 때 나타나는 결과
5. **주의:** 흔한 오류와 확인할 설정
6. **연결:** 다음 주제와 관련된 장면

## 버전 기준

프로젝트를 열 수 있는 Unity 버전은 `ProjectSettings/ProjectVersion.txt`를 기준으로 합니다. Unity를 업그레이드할 때는 별도 브랜치에서 열고, 장면이 정상적으로 로드되는지와 패키지 변경을 확인한 뒤 README의 버전을 갱신합니다.

## 이름 규칙

- 장면: `004-번호_주제_세부내용.unity`
- 스크립트: 기능이 드러나는 PascalCase
- 문서: 주제 중심의 짧은 제목

노션은 학습 메모와 개념 설명의 원본으로 사용하고, 저장소 README와 `docs/`는 실행 가능한 프로젝트 안내와 장면 인덱스로 유지합니다.
