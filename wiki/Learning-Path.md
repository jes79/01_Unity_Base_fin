# 학습 경로

| 단계 | 장면 범위 | 핵심 목표 |
|---|---|---|
| 1 | `004-01` ~ `004-04` | Transform, 이동, 회전, 점프 |
| 2 | `004-05` ~ `004-06` | Collision, Trigger, Rigidbody, CharacterController |
| 3 | `004-07` ~ `004-09` | 사운드, 카메라, Skybox |
| 4 | `004-10` ~ `004-11` | Prefab, Particle System |
| 5 | `004-12` ~ `004-17` | Raycast, API, Coroutine, 씬 전환, 메서드 호출, PlayerPrefs |
| 6 | `004-18` ~ `004-21` | UI, 모델링, Mecanim, KeyFrame Animation |

각 단계에서 다음 질문에 답할 수 있으면 다음 단계로 넘어갑니다.

- 어떤 컴포넌트가 핵심 동작을 담당하는가?
- Inspector에서 어떤 값을 바꿀 수 있는가?
- 코드와 씬 오브젝트는 어떻게 연결되는가?
- 문제가 생겼을 때 가장 먼저 확인할 설정은 무엇인가?
