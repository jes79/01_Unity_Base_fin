# Unity 기초 실습 저장소

Unity 핵심 기능을 작은 장면 단위로 확인하는 학습용 프로젝트입니다. 노션 교안의 항목과 `Assets/01.Scenes/004` 아래 실습 장면을 연결해, 필요한 주제를 바로 실행하고 확인할 수 있도록 정리했습니다.

## 빠른 시작

- **Unity 버전:** `6000.3.22f1` (Unity 6.3 기준)
- **권장 흐름:** [학습 경로](docs/learning-path.md) → [장면 카탈로그](docs/scene-catalog.md)
- Unity Hub에서 프로젝트를 추가한 뒤 위 버전으로 엽니다.
- `Assets/01.Scenes/004`에서 원하는 실습 장면을 열고 Play를 눌러 결과를 확인합니다.

## 프로젝트 범위

현재 저장소는 이동/회전/충돌/캐릭터 컨트롤러/사운드/카메라/프리팹/파티클/레이캐스트/코루틴/씬 전환/메서드 호출/PlayerPrefs/UI/모델링/애니메이션 예제를 포함합니다. TextMesh Pro 예제 패키지와 Unity 기본 패키지는 실습 실행에 필요한 범위에서 유지합니다.
